# DecisionMaker Pro 🎯

Production-grade Android decision-support app: analytical tools for
serious choices, playful physics for trivial ones — offline-first,
fully tested, CI-pipeable.

## Tools

| Tool | Answers | Signature capability |
|------|---------|---------------------|
| **Decision Matrix** | "Which option scores best across my weighted criteria?" | Confidence meter + sensitivity analysis |
| **Decision Tree** | "What's the best move when outcomes are uncertain?" | Rollback EMV + breakeven insight ("wins if odds > 33%") |
| **Marble Run** | "Let fate decide — fairly" | Seeded deterministic physics: same seed → bit-identical race |
| **History** | "What did I choose?" | Soft-delete + undo, analytics, deliberation timing |
